### ① 브랜드 DNA
- **브랜드명**: Microsoft Excel
- **한 줄 정체성**: 1985년 이후 세계 표준 스프레드시트 — 행/열 그리드 + 수식 + 차트의 정량 도구
- **공식 디자인 철학**: Microsoft 365 / Fluent 2 — "Calm, Optimistic, Inclusive"
- **시그니처 요소 1개**: Excel 그린(#107C41) 타이틀바 + Ribbon UI + 무한 격자. 셀 선택은 두꺼운 녹색 윤곽선

### ② 톤 & 무드
- **핵심 키워드 3개**: 정확, 격자, 신뢰
- **무드 설명**: 헤더만 그린, 본문은 흰색 격자. 셀 보더는 1px #D1D1D1, 행/열 헤더는 옅은 회색. 데이터 표시는 tabular-nums, 우측 정렬 숫자가 시그니처.
- **비주얼 스타일**: 모던 미니멀 (Fluent 2)
- **밀도(Density)**: Compact — 셀 높이 24px, 정보 밀도 최우선
- **모서리 성향**: Sharp (2~4px)
- **평면성**: Flat — 그림자는 팝오버/리본만

### ⑪ Anti-patterns
1. 셀에 라운드 모서리 적용 금지 — 격자 정렬 손실
2. 본문 셀에 가변폭 폰트 사용 금지 — tabular-nums 필수 (숫자 정렬)
3. 그림자로 셀 분리 금지 — 1px 보더만 사용
4. 그린을 본문 텍스트에 남발 금지 — 양수/증가 데이터, 헤더만
5. 셀 높이 32px 이상으로 키우지 말 것 — Compact 24px가 정보 밀도 표준
